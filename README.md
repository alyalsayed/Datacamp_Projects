# Datacamp_Projects

This repository contains a curated collection of data science projects completed on DataCamp, each exploring different domains, techniques, and datasets using Python and related technologies.

## Projects Overview

Below is a list of the projects included in this repository, each located in its own directory:

### 1. [ASL Recognition with Deep Learning](https://github.com/alyalsayed/Datacamp_Projects/tree/main/ASL%20Recognition%20with%20Deep%20Learning)
*Builds and trains deep learning models to recognize American Sign Language gestures from image data.*

### 2. [Analyzing Crime in Los Angeles](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Analyzing%20Crime%20in%20Los%20Angeles)
*Performs data analysis on crime datasets from Los Angeles to uncover patterns and trends.*

### 3. [Analyzing Students' Mental Health](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Analyzing%20Students'%20Mental%20Health)
*Examines survey data to understand factors affecting students' mental health.*

### 4. [Building a Retail Data Pipeline](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Building%20a%20Retail%20Data%20Pipeline)
*Demonstrates ETL and pipeline engineering for retail transaction datasets.*

### 5. [Classify Song Genres from Audio Data](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Classify%20Song%20Genres%20from%20Audio%20Data)
*Uses audio features and machine learning to classify music tracks by genre.*

### 6. [Clustering Antarctic Penguin Species](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Clustering%20Antarctic%20Penguin%20Species)
*Applies clustering algorithms to biological data to distinguish penguin species.*

### 7. [Exploring London's Travel Network](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Exploring%20London's%20Travel%20Network)
*Analyzes and visualizes public transport data for London, including journeys and network structure.*

  - Key files:  
    - [notebook.ipynb](https://github.com/alyalsayed/Datacamp_Projects/blob/main/Exploring%20London's%20Travel%20Network/notebook.ipynb): Main analysis and visualization notebook.
    - [tfl_journeys_final.csv](https://github.com/alyalsayed/Datacamp_Projects/blob/main/Exploring%20London's%20Travel%20Network/tfl_journeys_final.csv): Dataset of journeys.
    - [london.jpg](https://github.com/alyalsayed/Datacamp_Projects/blob/main/Exploring%20London's%20Travel%20Network/london.jpg), [tube.jpg](https://github.com/alyalsayed/Datacamp_Projects/blob/main/Exploring%20London's%20Travel%20Network/tube.jpg): Visual assets.

### 8. [Exploring the Evolution of Linux](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Exploring%20the%20Evolution%20of%20Linux)
*Investigates the development history and community aspects of the Linux operating system.*

### 9. [Investigating Netflix Movies](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Investigating%20Netflix%20Movies)
*Performs exploratory data analysis on Netflix movie offerings and characteristics.*

### 10. [Performing a Code Review](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Performing%20a%20Code%20Review)
*Showcases code review practices and automated quality checks on a sample project.*

### 11. [Predictive Modeling for Agriculture](https://github.com/alyalsayed/Datacamp_Projects/tree/main/Predictive%20Modeling%20for%20Agriculture)
*Develops machine learning models to predict agricultural outcomes from environmental data.*

## How to Use

1. **Clone the repository**:
   ```bash
   git clone https://github.com/alyalsayed/Datacamp_Projects.git
   ```
2. **Explore each project folder**: Each directory contains code, datasets, and (where available) notebooks or documentation for running the analyses.

3. **Dependencies**: Most projects use Python (Jupyter notebooks), and may require libraries like pandas, numpy, matplotlib, scikit-learn, etc. Refer to any `requirements.txt` or notebook instructions per project.
